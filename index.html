Dúvidas

Perguntas frequentes

O sistema funciona sem internet?

Sim. No Inspect, o checklist e o registro de tarefas ficam salvos no aparelho e sincronizam quando o sinal volta, sem duplicar nada. No Fleet, o computador de bordo registra embarques e posição e envia depois.

Preciso contratar tudo junto?

Não. Os sistemas são independentes e, dentro do Fleet, os módulos são vendidos separadamente: o cliente contrata o que precisa e o sistema esconde o resto.

Funciona no celular?

Sim. Os dois sistemas abrem no navegador e instalam como aplicativo (PWA). Também há versões Android para o dia a dia de campo.

Meus dados ficam misturados com os de outras empresas?

Não. Cada empresa enxerga apenas os próprios dados, com perfis de acesso por função (como inspetor, mecânico, gestor e administrador).

Dá para levar os dados para o Power BI?

Sim. O Inspect já traz views preparadas para Power BI, e também fazemos dashboards e integrações sob medida.
